# pong-lite

最小乒乓球模拟器:球速/挡板反弹角度/墙壁反弹/计分,加上双方 AI 的无头演示。纯标准库。

## 玩法

这是**无头模拟器**,没有实时键盘输入(小巧取舍):

```bash
python -m pong_lite --auto --seed 42          # 20 回合演示
python -m pong_lite --auto --rallies 100 --show  # 显示每次得分棋盘
```

## 物理规则

- 球速度 `(vx, vy)`;撞上/下墙翻转 `vy`
- 撞挡板翻转 `vx`,且 `vy` 按击球位置给出:越靠近挡板边缘,竖直速度越大(`hit` -1..+1 → `vy = 1.6×hit`)
- 球越过挡板线对方得 1 分,重新发球
- 双方 AI 挡板以有限速度追踪球(只在球靠近自己半区时追)

## 真实验证

- `py_compile` 通过
- 单元测试:墙反弹翻转 `vy`、挡板反弹翻转 `vx`、错过挡板对方得分、击球位置决定 `vy`(上沿正、下沿负、中心 0)
- `--auto --rallies 20 --seed 42` 正常完成并打印比分

## 已知局限

- 无实时键盘输入,只有 `--auto` 演示
- AI 挡板速度足够时几乎不丢球,演示比分往往接近;调小 `--ai-speed` 可制造失误
- 无音效、无最高分存档
